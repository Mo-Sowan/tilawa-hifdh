# Roadmap

## Done

- Duolingo-style progress visuals, streaks, XP, plans and reminders.
- Surah navigator and self-assessment flow.
- Mushaf reader with annotations, served through a caching proxy.
- Offline on-device recitation follow-along.
- Google and Apple sign-in with a multi-user API.
- Local persistence with sync to the account.

## Next

- Word-level Mushaf highlighting driven by tracker word progress (the overlay
  model already reserves `words`).
- Ayah coordinate data for the scanned pages, imported through a reviewed
  pipeline with provenance.
- Recitation history and per-surah accuracy trends in the progress view.
- Teacher notes and shared plans.
- Export progress to a file the user can keep.
