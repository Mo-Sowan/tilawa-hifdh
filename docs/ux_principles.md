# UX Principles

## Visual Inspiration

Use Duolingo-like motivation:

- progress path,
- streaks,
- XP,
- friendly completion states,
- prominent daily action.

Use Tarteel-like restraint:

- calm typography,
- elegant Surah navigation,
- dark-mode polish,
- Quran-appropriate seriousness.

## Primary UX Rule

The app should help the user revise, not test Quran content.

The fastest path should be:

1. Open dashboard.
2. Tap priority Surah or another Surah.
3. Revise externally.
4. Record self-estimate.

## Dashboard

Dashboard should include:

- status bar,
- reminder banner,
- priority Surah card,
- plan button,
- Tarteel-style Surah navigator.

## Surah Detail

Surah detail should include:

- Surah name and metadata,
- mastery/progress,
- self-estimation slider,
- save estimate,
- add/remove from plan.

## Avoid

- Quran MCQs.
- Missing-word Quran questions.
- Word sorting Quran chips.
- “Correct/incorrect” Quran validation.
- Any generated Quran text.
