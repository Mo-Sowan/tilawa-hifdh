# Visual Direction

## Goal

Use Duolingo-style motivation without copying Quran quiz mechanics.

## Theme

- Dark and light modes.
- Deep slate dark background.
- Clean light background.
- Mint/emerald for progress.
- Amber for reminders and due revision.

## Navigation

Surah navigation should feel closer to Tarteel:

- elegant rows/cards,
- clear Arabic/English names,
- readable metadata,
- progress rings,
- no clutter.

## Components

- Priority Surah card.
- Surah navigator tile.
- Self-assessment slider.
- Revision plan chips.
- Reminder banner.

## Avoid

- Quiz answer tiles.
- Quran word sorting chips.
- Any UI suggesting the app judges Quran correctness.
